## Domain Kustom (Opsional)

Jika platform deploy kamu mendukung custom domain, kamu bisa pakai domain sendiri.

Domain final yang dipakai tim:

- [https://www.igaruda.id](https://www.igaruda.id)

Instruksi DNS singkat:

1. Buka pengaturan DNS di penyedia domain kamu.
2. Tambahkan record sesuai instruksi dari platform deploy (biasanya `CNAME` untuk `www` ke target platform).
3. Tunggu propagasi DNS.
4. Setelah aktif, pastikan website bisa dibuka dari domain final di atas.
