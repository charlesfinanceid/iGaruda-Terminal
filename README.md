# iGaruda Terminal

A dark-mode, high-density prototype terminal interface focused on Indonesian capital markets (IDX).

## Features in this prototype

- Institutional-style multi-panel terminal layout
- Top command/search bar with quick command mode
- Watchlist, market heatmap, sector analysis, screener, and news feed
- Market breadth, order flow, and portfolio tracker side insights
- Bottom ticker-style market update console

## Run locally

```bash
python3 -m http.server 4173
```

Open <http://localhost:4173>.
